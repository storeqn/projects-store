# متجر مشاريعي الرقمية

موقع عربي RTL جاهز لعرض:
- المواقع
- التطبيقات
- الأنظمة
- المشاريع الجاهزة للبيع
- الاشتراكات الشهرية
- خدمات التطوير المخصص

## التعديل السريع
1. افتح `script.js`.
2. غيّر رقم واتساب في:
   `WHATSAPP_NUMBER`
3. عدّل قائمة `projects` لإضافة مشاريعك وروابط التجربة.
4. غيّر اسم الموقع والنصوص من `index.html`.

## النشر
يمكن رفع الملفات مباشرة إلى:
- GitHub Pages
- Cloudflare Pages
- Netlify

لا يحتاج قاعدة بيانات في نسخته الحالية.
